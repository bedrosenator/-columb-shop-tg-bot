Telegram-бот на базе **NestJS** и **Telegraf** для автоматизации сбора ежедневных финансовых отчётов с розничных торговых точек (магазинов) сети **Columb Shop**. 

Бот помогает продавцам быстро отправлять данные о кассе, безналичном обороте, расходах и зарплатах прямо с телефона с прикреплением фотографии бумажного отчёта, а руководству — получать структурированные отчёты в общую группу и экспортировать данные в Excel.

---

## 🚀 Основные возможности

1. **Пошаговый мастер заполнения отчётов (Wizard)**:
   - 🏪 Выбор существующего магазина из списка (или добавление нового).
   - 💵 Сумма наличных в кассе.
   - 💳 Безналичный оборот через банковский терминал.
   - 🌅 Утренний баланс кассы.
   - 📉 Расходы за текущий день.
   - 💰 Выплаченная зарплата.
   - 📷 Загрузка фотографии бумажного отчёта.
2. **Пересылка отчётов руководству**:
   - Автоматическая группировка данных и пересылка отчёта вместе с прикрепленным фото в рабочую Telegram-группу в реальном времени.
3. **Панель Администратора**:
   - Специальные кнопки для пользователей с правами администратора.
   - 📊 **Экспорт в Excel**: Выгрузка всей истории расходов и доходов магазинов в структурированный Excel-файл с авто-подбором ширины колонок и стилизацией шапки.
4. **Безопасность и хранение**:
   - Вся история транзакций и отчётов сохраняется в локальную реляционную базу данных SQLite с помощью Prisma ORM.

---

## 🛠 Стек технологий

- **Фреймворк**: NestJS (v11)
- **Telegram Bot API**: Telegraf + `nestjs-telegraf`
- **База данных**: SQLite (через быстрый драйвер `better-sqlite3` и Prisma ORM)
- **Генерация документов**: ExcelJS (для отчетов в формате `.xlsx`)
- **Язык**: TypeScript

## 🔧 Локальный запуск (Разработка)

### 1. Установка зависимостей
```bash
pnpm install
```

### 2. Настройка окружения
Создайте файл `.env` на основе шаблона и заполните его:
```bash
cp .env.example .env
```

Пример содержимого `.env`:
```env
APP_PORT_HOST=3001
TG_BOT_TOKEN="ВАШ_ТОКЕН_TELEGRAM_БОТА"
TG_GROUP_ID="-100xxxxxxxxx"  # ID группы, куда бот будет слать отчеты
TG_ADMIN_ID="xxxxxxxxx"      # ID вашего Telegram аккаунта для админ-панели
DATABASE_URL="file:./dev.db"
```

### 3. Накатывание миграций БД и Сидирование
Сгенерируйте клиент Prisma, запустите миграции и добавьте список стандартных магазинов в БД:
```bash
npx prisma generate
npx prisma migrate dev --name init
npx prisma db seed
```

### 4. Запуск в режиме разработки
```bash
pnpm run start:dev
```

## 🐳 Развёртывание в продакшн (Production)

Проект полностью готов к продакшн-деплою на любой Linux-сервер (VPS).

### Способ 1: С использованием Docker Compose (Рекомендуемый)

В корне проекта настроены `Dockerfile` и `docker-compose.yml`. SQLite-база данных монтируется во внешний volume, что предотвращает потерю данных при перезапуске контейнера.

1. Установите Docker и Docker Compose на сервер.
2. Склонируйте репозиторий и настройте `.env` файл.
3. Запустите стек контейнеров одной командой:
   ```bash
   docker-compose up -d --build
   ```
4. Посмотреть логи бота в реальном времени:
   ```bash
   docker-compose logs -f app
   ```

### Способ 2: С использованием PM2 (Нативно)

Если вы не хотите использовать Docker, вы можете запустить бота с помощью менеджера процессов PM2:

1. Установите PM2 глобально:
   ```bash
   pnpm install -g pm2
   ```
2. Подготовьте БД и соберите проект:
   ```bash
   npx prisma generate
   npx prisma migrate deploy
   npx prisma db seed
   pnpm run build
   ```
3. Запустите приложение:
   ```bash
   pm2 start dist/src/main.js --name "columb-shop-bot"
   ```
4. Для сохранения процессов при перезапуске системы выполните:
   ```bash
   pm2 startup
   pm2 save
   ```

## 📂 Структура проекта

* `src/main.ts` — точка входа приложения NestJS.
* `src/app.module.ts` — корневой модуль с регистрацией Telegraf и Prisma.
* `src/bot/` — логика Telegram-бота:
  * `bot.update.ts` — обработка основных команд бота (`/start`, кнопка вызова отчёта, кнопка экспорта Excel).
  * `report.wizard.ts` — пошаговый сценарий (Wizard) опроса продавца для составления отчёта.
  * `report.service.ts` — бизнес-логика сохранения отчётов в базу данных и форматирования сообщений для отправки в группу.
* `src/excel/` — сервис для генерации Excel-отчетов на основе данных из БД с использованием `exceljs`.
* `prisma/` — схема базы данных (`schema.prisma`), миграции и скрипт первоначального наполнения (`seed.ts`).
