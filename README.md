## Description

[Nest](https://github.com/nestjs/nest) framework TypeScript starter repository.

## Project setup

```bash
$ pnpm install
```

## Compile and run the project

```bash
# development
$ pnpm run start

# watch mode
$ pnpm run start:dev

# production mode
$ pnpm run start:prod
```

## Docker & Docker Compose (Запуск в контейнерах)

В проекте настроен Docker Compose для локального запуска NestJS приложения и базы данных PostgreSQL.

### Шаг 1: Конфигурация `.env`
Создайте локальный файл `.env` на основе шаблона (он уже должен быть создан по умолчанию):
```bash
$ cp .env.example .env
```
В файле `.env` вы можете переопределить порты, если они конфликтуют с другими запущенными сервисами:
* `APP_PORT_HOST` (по умолчанию `3001` для избежания конфликтов с локальным портом `3000`).
* `DB_PORT_HOST` (по умолчанию `5433` для избежания конфликтов с дефолтным портом PostgreSQL `5432`).

*Примечание: Доступ к порту базы данных `DB_PORT_HOST` ограничен только для `localhost` (`127.0.0.1`), база данных скрыта от внешнего интернета в целях безопасности.*

### Шаг 2: Запуск сервисов

Запустите базу данных и приложение одной командой:
```bash
# Запуск всего стека в фоновом режиме (detached)
$ docker-compose up -d
```

Если вам нужно запустить только базу данных PostgreSQL (например, если вы хотите запускать NestJS локально в режиме watch):
```bash
# Запуск только PostgreSQL в фоновом режиме
$ docker-compose up -d db
```

### Шаг 3: Проверка статуса и логов
```bash
# Проверить запущенные контейнеры
$ docker ps

# Посмотреть логи приложения
$ docker-compose logs -f app

# Посмотреть логи базы данных
$ docker-compose logs -f db
```

### Сборка приложения
Для пересборки образа (например, после изменения `package.json` или других файлов):
```bash
$ docker-compose build app
# или запуск с пересборкой
$ docker-compose up -d --build
```

## Run tests

```bash
# unit tests
$ pnpm run test

# e2e tests
$ pnpm run test:e2e

# test coverage
$ pnpm run test:cov
```

## Deployment

When you're ready to deploy your NestJS application to production, there are some key steps you can take to ensure it runs as efficiently as possible. Check out the [deployment documentation](https://docs.nestjs.com/deployment) for more information.

If you are looking for a cloud-based platform to deploy your NestJS application, check out [Mau](https://mau.nestjs.com), our official platform for deploying NestJS applications on AWS. Mau makes deployment straightforward and fast, requiring just a few simple steps:

```bash
$ pnpm install -g @nestjs/mau
$ mau deploy
```

With Mau, you can deploy your application in just a few clicks, allowing you to focus on building features rather than managing infrastructure.
